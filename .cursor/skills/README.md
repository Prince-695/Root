# Project Cursor skills

Skills are installed via [`skills.sh`](https://skills.sh/) (`npx skills add … -a cursor -y`) into:

- `.agents/skills/` — skills CLI install location + `skills-lock.json` at repo root
- `.cursor/skills/` — mirrored copies for Cursor project skills (plus custom `root-cli`)

See [docs/phase/phase-1.md](../../docs/phase/phase-1.md) for the full installed list.
